# Muhammad Amjid Portfolio

A responsive personal portfolio with three profile experiences: **Executive** (default), **Editorial**, and **Cinematic**. Neumorphic is the default colour theme, with Midnight and Warm Paper alternatives. All profile experiences use the same verified career and project information.

## Live profiles

- **GitHub Pages:** https://amjidofficial.github.io/Profile/
- **Netlify:** https://mamjid.netlify.app/

Both hosts are intended to serve this same repository and the same static site. GitHub Pages deploys on pushes to `main`. Netlify should be connected to this repository with the repository root as its publish directory and no build command.
